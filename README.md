# Search Articles Mini-App

A simple React application using Vite that allows you to instantly search through a list of articles. Matches are beautifully highlighted.

## Setup & Run Instructions

Follow these simple steps to run the application locally:

### 1. Install Dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

### 3. View the App
Your terminal will provide a local URL (`http://localhost:5173/`).
Ctrl+Click or open that link in your browser to see the app!
